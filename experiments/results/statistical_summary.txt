                                 Severe Non-IID R95=10.1 rounds vs IID Baseline R95=4.0 rounds → +152.5% delay

  Component 1 — Data Heterogeneity Alone (Baseline IID → Baseline Non-IID):
    R95: 4.0 → 6.0 rounds  → +2.0 rounds  (+50%)

    Rural Zambia:        6.0 → 7.3 rounds  → +1.3 rounds  (+22%)
    Severe Disruption:   6.0 → 10.1 rounds → +4.1 rounds (+68%)

  Total compound delay (reproduces original figures):
    Rural:   4.0 → 7.3 rounds  = +3.3 rounds (+82%) = data delay (2.0r) + network delay (1.3r)
    Severe:  4.0 → 10.1 rounds = +6.1 rounds (+152%) = data delay (2.0r) + network delay (4.1r)

Conclusion: Under non-IID data skew alone (ideal network), convergence to R95 required 6.0 rounds — a 2.0-round delay
attributable to Dirichlet partitioning. Network impairment added a further 1.3 rounds (Rural) and 4.1 rounds (Severe)
above this non-IID baseline. The +82.5%/+152.5% figures reported in the thesis reflect both components jointly, as now disclosed.
